## ✨ Funcionalidades

- 🎮 Física de voo com gravidade e salto
- 📱 Responsivo — funciona em desktop e mobile
- 💰 Sistema de moedas coletáveis nos tubos
- ⚡ Power-up **2x moedas** (temporário, 10 segundos)
- 🎨 **10 skins** de pássaro desbloqueáveis
- 🛒 Loja com sistema de compra por moedas
- 💾 Progresso salvo automaticamente (localStorage)
- 🏆 Placar com melhor score
- 🎬 Animações de início e morte

## 🗂️ Estrutura do Projeto

```
flappy-bird/
├── index.html
├── style.css
└── js/
    ├── bird.js    # Pássaro e todas as skins
    ├── pipes.js   # Tubos, moedas e power-ups
    └── game.js    # Loop principal, física e UI
```

## 🚀 Como Rodar Localmente

1. Clone ou baixe o repositório
2. Abra o arquivo `index.html` no navegador
3. Ou use uma extensão como **Live Server** no VS Code

Não precisa instalar nada.
